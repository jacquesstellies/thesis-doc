\chapter{Underactuated Controller Design}
\label{chap:underactuated_controller}

\section{Introduction}
The underactuated system described in \autoref{chap:modelling} is a highly non-linear system thus traditional LTI control methods are not directly applicable. As discussed as part of the literature review in chapter \ref{chap:literature_review}, the backstepping controller is a suitable control method for underactuated systems. In this chapter, the underactuated backstepping controller designed by Nadafi and Kabganian \cite{nadafiRobustBacksteppingAttitude2021} is analysed and its properties are discussed. A key defining feature of this controller is that it can achieve attitude tracking control i.e.: tracking a desired attitude profile under certain constraints, where most works are limited to regulation. It will be shown that this controller is robust to external disturbances, varying moment of inertia, reaction wheel torque disturbances and is performant in contrast to a control method such as model predictive control. This latter benefit is highly valuable on limited compute resources such as a satellite. This chapter will also discuss the controllability of the underactuated system and the limitations of the backstepping controller. A possible future modification to this controller is discussed using a technique developed by Haochang Tian in \cite{tianUnderactuatedTethered}. This controller uses a similar backstepping methodology but contains a modification to the kinematic virtual control input to excite the actuated axes during a slew manoeuvre. Simulation results are presented which illustrate key constraints of the design and its tracking performance.

\section{Controllability}
\label{sec:controllability}
As mentioned in section \ref{underactuated_lit_review}, a controllability analysis of an underactuated satellite is presented in \cite{aeyelsStabilizationNonLinear} by Aeyels. They show that a satellite with 2 reaction wheels is globally asymptotically stable by either a discontinuous or a smooth, time-varying feedback control law. It is also shown that it is not controllable via a smooth time invariant control law. The authors prove that their proposed control law can achieve global asymptotic stability for the system via the centre manifold theorem. In \cite{aeyelsComments} Aeyels and Szafranski show that a key requirement is that the total angular momentum of the satellite must be zero $\vec{H} = 0$ in order to achieve stability. 

Nadafi and Kabganian \cite{nadafiRobustBacksteppingAttitude2021} build on this work and present a time-varying backstepping controller.

\section{Backstepping}
\label{subsec:backstepping_procedure}
In order to understand the backstepping controller designed by Nadafi and Kabganian \cite{nadafiRobustBacksteppingAttitude2021}, it is necessary to understand the backstepping procedure. Backstepping is a non-linear design technique for stabilising the origin of a system in strict-feedback form. It entails designing a series of virtual control inputs each of which stabilises a subsystem and ultimately the overall system. The method is recursive in that the controller for the $i^{th}$ subsystem depends on the controller for the $(i-1)^{th}$ subsystem. The satellite kinematic and dynamic equations represent a 2nd order cascade system. A Lyapunov function is selected for each subsystem and the control law is designed to force the time derivative to this surface.

The satellite attitude kinematics and dynamics can be viewed as two subsystems connected in cascade: the dynamics subsystem is driven directly by the control input $\vec{u}$, while the kinematics subsystem is driven only indirectly, through the angular velocity produced by the dynamics subsystem. This mirrors the general backstepping structure of equation \eqref{eq:1}, with the dynamics playing the role of the inner subsystem $i$ and the kinematics playing the role of the outer subsystem $i-1$ whose virtual control input is designed first. This simplified cascade structure is illustrated in Figure~\ref{fig:cascade_simplified}; the full expressions for $f$ and $g$ are given later in this chapter once the underactuated case has been introduced (equations \eqref{eq:cascade_dyn} and \eqref{eq:cascade_kin}).

\subsection{Lyapunov Functions}
To prove the stability of a non-linear system around an equilibrium point, a Lyapunov function is used. An equilibrium point is stable if all solutions starting close to the equilibrium point remain close to it for all time. An equilibrium point is asymptotically stable if it is stable and all solutions starting close to the equilibrium point converge to it as time goes to infinity. A Lyapunov function is a scalar function that is used to prove the stability of an equilibrium point of a dynamical system. It is a mathematical tool that provides a way to analyse the behaviour of a system without explicitly solving its equations of motion. The basic idea behind Lyapunov functions is to find a function that decreases over time along the trajectories of the system, indicating that the system is moving towards a stable equilibrium point. Formally, let x = 0 be an equilibrium point of the system $\dot{x} = f(x)$ where $f : D \rightarrow \mathbb{R}^n$ is a locally Lipschitz map from a domain $D \subset \mathbb{R}^n$ into $\mathbb{R}^n$ containing $x=0$.

The equilibrium point is stable if for each $\epsilon > 0$, there exists a $\delta > 0$ such that if $\|x(0)\| < \delta$, then $\|x(t)\| < \epsilon$ for all $t \geq 0$.

\input{chapter_4/lyapunov_stability}

 A Lyapunov function is a scalar function $V : D \rightarrow \mathbb{R}$ that is continuously differentiable and satisfies the following conditions:
\begin{equation}
    V(0) = 0, \quad V(x) > 0 \quad \forall \ x \in D, x \neq 0
\end{equation}
\begin{equation}
    \dot{V}(x) \leq 0 \quad \forall \ x \in D
\end{equation}
then x is stable. If
\begin{equation}
    \dot{V}(x) < 0 \quad \forall \ x \in D, x \neq 0
\end{equation}
then x is asymptotically stable. If D = $\mathbb{R}^n$ and V is radially unbounded then x is globally asymptotically stable \cite{khalilNonlinearSystems2002}.

 A Lyapunov function $V(\vec{x})$ is positive definite if $V(0)=0$ and $V(\vec{x})>0$ for all $\vec{x}\neq0$. It is radially unbounded if $V(\vec{x})\rightarrow\infty$ as $\vec{x}\rightarrow\infty$. A Lyapunov function is used to prove the stability of a system by showing that the time derivative of the Lyapunov function is negative definite i.e.: $\dot{V}(\vec{x}) \leq -W(\vec{x})$ where $W(\vec{x})$ is a positive definite function or equivalently $\dot{V}(\vec{x})<0$ for all $\vec{x}\neq0$. If this is true then the system is stable. 

A common Lyapunov function chosen for electro-mechanical systems is the total energy of a system (pendulums, robot manipulators, converters, ship dynamics), since total energy V = kinetic + potential is already a natural positive-definite candidate. However this is not a requirement and other Lyapunov functions can be used as long as they satisfy the conditions of being positive definite and differentiable \cite{khalilNonlinearSystems2002}.
\subsection{Backstepping Procedure}
Using the Lyapunov stability theory, the backstepping procedure is outlined in \cite{khalilNonlinearSystems2002} as follows. Take the following 2nd order equation:

\begin{equation}
    \dot{\eta} = f(\eta) + g(\eta)\xi \label{eq:1}
\end{equation}
\begin{equation}
    \dot{\xi} = u
\end{equation}

where $f(0)=0$ and g is non-zero over the region of interest.
The goal is to design a control law $u$ such that the origin $\eta=0$ is asymptotically stable i.e.: $(\eta, \xi)$ returns to $(0,0)$ after starting from some arbitrary initial condition.

\textbf{Step 1: Treat $\xi$ as a virtual control.} Assume that equation \eqref{eq:1} can be stabilised by a smooth state feedback law $\xi=\phi(\eta)$ with $\phi(0)=0$, i.e. the subsystem
\begin{equation}
    \dot{\eta} = f(\eta) + g(\eta)\phi(\eta)
\end{equation}
has an asymptotically stable origin. Then there is a Lyapunov function $V(\eta)$ satisfying

\begin{equation}
\begin{split}
    \dot{V} &= \frac{\partial V}{\partial \eta}\frac{d \eta}{dt} \\
    &= \frac{\partial V}{\partial \eta}[f(\eta) + g(\eta)\phi(\eta)] \leq -W(\eta), \quad \forall \ \eta \in D
\end{split}
\end{equation}

where $W(\eta)$ is a positive definite function. Note that $\xi=\phi(\eta)$ is only the \textit{desired} value of $\xi$. In reality $\xi$ is a state that is only driven by $u$, so in general $\xi \neq \phi(\eta)$.

\textbf{Step 2: Define the error from the desired value.} The change of variables
$$ z = \xi - \phi(\eta) $$
gives the error between the actual value of $\xi$ and the desired value $\phi(\eta)$, with $z=0$ meaning $\xi=\phi(\eta)$. Adding and subtracting $g(\eta)\phi(\eta)$ on the righthand side of equation \eqref{eq:1} and substituting $z$ gives the new system equations:
\begin{align}
    \dot{\eta} &= [f(\eta) + g(\eta)\phi(\eta)] + g(\eta)z \\
    \dot{z} &= u - \dot{\phi}
\end{align}
and 
\begin{equation}
\qquad \dot{\phi} = \frac{\partial \phi}{\partial \eta} [f(\eta) + g(\eta)\xi]
\end{equation}

which is shown in figure \ref{fig:backstepping} b) and c). Going from b) to c) is called backstepping because the virtual control input $-\phi(\eta)$ is stepped back through the integrator. The bracketed term is the stable subsystem from Step 1, and $g(\eta)z$ is the perturbation from $\xi$ not yet matching $\phi(\eta)$.

\textbf{Step 3: Cascade form.} Taking $v = u - \dot{\phi}$ gives the cascade connection
$$ \dot{\eta} = [f(\eta) + g(\eta)\phi(\eta)] + g(\eta)z  $$
$$ \dot{z} = v $$

This modified system is similar to the starting system however now the inner subsystem has an asymptotically stable origin when the input is zero. We can now choose a candidate Lyapunov function for the overall system:

$$ V_c (\eta,\xi) = V(\eta) + \frac{1}{2}z^2 $$

from which we obtain
\begin{align}
    \dot{V_c} &= \frac{\partial V}{\partial \eta}[f(\eta) + g(\eta)\phi(\eta)] + \frac{\partial V}{\partial \eta}g(\eta)z + zv \\
    &\leq -W(\eta) + \frac{\partial V}{\partial \eta}g(\eta)z + zv
\end{align}

Choosing $v$ such that it cancels out the 2nd last term from the above

$$ v = -\frac{\partial V}{\partial \eta}g(\eta) - kz, \; k > 0 $$

gives us

$$ \dot{V_c} = -W(\eta) - kz^2 $$

where k influences the rate of convergence.
This shows that the origin $(\eta=0, z=0)$ is asymptotically stable. Since $\phi(0) = 0$ we know that the origin $(\eta=0, \xi=0)$ is also asymptotically stable. Substituting for $v$, $z$ and $\phi$ we obtain the control law for the system:

\begin{equation}
    u =  \frac{\partial \phi}{\partial \eta} [f(\eta) + g(\eta)\xi] - \frac{\partial V}{\partial \eta}g(\eta)z - k[\xi - \phi(\eta)]
\end{equation}

If all assumptions hold globally and $V(\eta)$ is radially unbounded then that origin is globally asymptotically stable.
This idea can be extended to higher order systems.

\section{Nadafi and Kabganian Controller}

Nadafi and Kabganian \cite{nadafiRobustBacksteppingAttitude2021} present a robust backstepping attitude tracking controller for an underactuated spacecraft equipped with two reaction wheels, addressing the coupled kinematic--dynamic (cascade) model in the presence of actuator saturation and time-varying perturbations. They name this controller the FNDO-BS (`Finite-Time Nonlinear Disturbance Observer`-`Backstepping`) Controller. The key contribution is a novel hypersurface that stabilises the unactuated attitude degrees of freedom via virtual inputs, enabling full asymptotic convergence of both angular velocity error and quaternion error using only two torques. They require no limitations on the reference quaternion.

\subsection{Cascade Model}

To design the controller, Nadafi and Kabganian consider the reduced spacecraft model error i.e.: the actuated dynamics and kinematics. In order to ensure the robustness of their controller actuator faults as a bounded disturbance $\dot{h}_{dw}$ on the actuated dynamics and assume some constant effectiveness reduction $\rho_w = 0$ on the actuated wheels

\begin{equation}
    \dot{h}_{dw} = \rho_w \dot{h}_w
\end{equation}

Under the assumptions (z-axis is the unactuated axis; total angular momentum is zero so $\omega_z = 0$), the full spacecraft dynamics reduce to a two-part cascade system in the actuated angular velocity error $\boldsymbol{\omega}^r_e = [\omega_{ex},\, \omega_{ey}]^T \in \mathbb{R}^2$ and the quaternion error vector $\vec{q}_e \in \mathbb{R}^3$:
\begin{equation}
    \begin{split}
        \dot{\vec{q}}_e = \frac{1}{2}\begin{bmatrix}
            q_{e0} & -q_{e3} \\
            q_{e3} &  q_{e0} \\
            -q_{e2} &  q_{e1}
        \end{bmatrix} \label{eq:cascade_kin}
        \vec{\dot{\omega}_e^r}
        = A(\vec{q}_e)\vec{\dot{\omega}_e^r}
    \end{split}
\end{equation}

\begin{equation}
\begin{split}
        \vec{\dot{\omega}}^r_e &= \{\vec{J}^r\}^{-1}\dot{\vec{h}}^r_w - \vec{C}^r \vec{\dot{\omega}}_d^r + \{ c_{31} \omega_{dx} + c_{32} \omega_{dy}\}[\omega_{ey} \ -\omega_{ex}]^T + \{\vec{J}^r\}^{-1} \vec{T}_d^r + \{\vec{J}^r\}^{-1} \vec{\rho_w} \dot{\vec{h}}_w^r \\
    &= \vec{u} + \vec{F} + \vec{d} \label{eq:cascade_dyn} \\
\end{split}
\end{equation}
where $\vec{u} = \{\vec{J}^r\}^{-1}\dot{\vec{h}}^r_w \in \mathbb{R}^2$ is the control input (reaction wheel torque), $\vec{F} = - \vec{C}^r \vec{\dot{\omega}}_d^r + \{ c_{31} \omega_{dx} + c_{32} \omega_{dy} \} [\omega_{ey} \ -\omega_{ex}]^T$ captures the known gyroscopic and reference-trajectory terms and $\vec{d} = \{\vec{J}^r\}^{-1} (\vec{T}_d^r + \vec{\rho_w} \dot{\vec{h}}_w^r)$ is the lumped disturbance, which includes external disturbances and internal reaction wheel disturbances. Notice that $\vec{\rho_w} \in \mathbb{R}^{2\times2}$ is the complement of the actuator effectiveness matrix $\vec{E} = \vec{I} - \vec{\rho_w}$ defined in section \ref{chap:modelling}. The control input $\vec{u}$ will be designed to drive the actuated angular velocity error $\boldsymbol{\omega}^r_e$ to zero in the following sections.

\subsection{Virtual Control Input Design}
\label{subsec:hypersurface_design}

The unactuated quaternion error $q_{ez}$ cannot be driven directly by $\vec{u}$; it is driven only through the kinematic equation \eqref{eq:cascade_kin} via $\boldsymbol{\omega}^r_e$. It is important to note that this is exploiting the kinematic (not gyroscopic) coupling between the actuated and unactuated states. No gyroscopic torque is involved, instead this takes advantage of the Lie bracket geometry. The unactuated states are influenced in a manner analogous to nonholonomic steering. To illustrate this, consider the kinematic equation for the unactuated quaternion error rate:

\begin{equation}
    \dot{q}_{e3} = \frac{1}{2}(-q_{e2}\omega_{ex} + q_{e1}\omega_{ey})
\end{equation}

It is clear that the unactuated quaternion error $q_{e3}$ is driven by the actuated angular velocity error $\boldsymbol{\omega}^r_e$ through the actuated quaternion errors $q_{e1}$ and $q_{e2}$. If the actuated quaternion errors are zero or the actuated angular velocity error is zero, then the unactuated quaternion error is not driven at all. This is a key limitation of the controller which will be discussed in more detail later in this chapter. As such the controller is designed for tracking a desired attitude profile rather than regulation to a fixed attitude. 

 So Nadafi and Kabganian define a virtual input hypersurface $\boldsymbol{\omega}^r_e = \boldsymbol{\Phi}(\vec{q}_e)$, with $\boldsymbol{\Phi}(\vec{0}) = \vec{0}$, such that $\vec{q}_e \to \vec{0}$ when the actuated states lie on the surface.

The choice
\begin{equation}
    \boldsymbol{\Phi}(\vec{q}_e) = -2\begin{bmatrix}
        a q_{e2} q_{e3} + \lambda_1 q_{e0} q_{e1} \\
        b q_{e1} q_{e3} + \lambda_2 q_{e0} q_{e2}
    \end{bmatrix}, \quad a = \lambda_2 - \lambda_3,\quad b = \lambda_3 - \lambda_1
    \label{eq:hypersurface}
\end{equation}
with constants $\lambda_i > 0$, $|\lambda_1| = |\lambda_2|$, and $|a| \leq |\lambda_1|$, guarantees that the unactuated quaternion error $\vec{q}_e \to \vec{0}$ asymptotically.

The proof chooses the Lyapunov function 
\begin{equation}
    V_a = \frac{1}{2}\vec{q}_e^T \Lambda \vec{q}_e
\end{equation}

with $\Lambda = \mathrm{diag}(\lambda_1, \lambda_2, \lambda_3)$. Taking the time derivative and substituting equation \eqref{eq:hypersurface} yields $\dot{V}_a$ negative semi-definite, and LaSalle's invariance principle then shows that the only invariant set where $\dot{V}_a = 0$ is the origin $\vec{q}_e = \vec{0}$. See Appendix~\ref{appen:derivations_nadafi_backstepping} for the full proof of asymptotic stability of $\vec{q}_e$.

\subsection{Disturbance Observer}

The backstepping controller relies on the hypersurface defined by equation \eqref{eq:hypersurface} to steer the unactuated axis. The actuated states have to sit on that surface for the argument to hold. Any external or internal disturbance is not captured by the dynamics the hypersurface relies on. Thus a persistent estimation error in the lumped disturbance would push the system off of the surface and lead to instability. To estimate $\vec{d} \in \mathbb{R}^2$ Nadafi and Kabganian employ a finite-time nonlinear disturbance observer (FNDO) presented in \cite{shihuaDisturbanceObserverBasedControl}. This is a sliding-mode observer that estimates $\vec{d}$ in finite time. It handles the disturbances and uncertainties in a robust manner simply with a fast response time \cite{huQinglei2014Dobf}. The FNDO is given by:
\begin{align}
    \dot{\boldsymbol{\chi}}_0 &= \boldsymbol{\nu}_0 + \vec{u} + \vec{F}, \quad
    \boldsymbol{\nu}_0 = -\kappa_0\,\mathrm{diag}\!\left(L^{1/2}|\boldsymbol{\chi}_0 - \boldsymbol{\omega}^r_e|^{1/2}\right)\mathrm{sign}(\boldsymbol{\chi}_0 - \boldsymbol{\omega}^r_e) + \boldsymbol{\chi}_1 \notag \\
    \dot{\boldsymbol{\chi}}_1 &= -\kappa_1 L\,\mathrm{sign}(\boldsymbol{\chi}_1 - \boldsymbol{\nu}_0)
\end{align}
where $\boldsymbol{\chi}_1$ converges to $\vec{d}$ for suitable choices of parameters $\kappa_0, \kappa_1 > 0$ and $L$.

\subsection{Backstepping Control Law}

With the variable transformation $\vec{Z} = \boldsymbol{\omega}^r_e - \boldsymbol{\Phi}(\vec{q}_e)$ measuring deviation from the hypersurface, the FNDO-based backstepping (FNDO-BS) control law is:
\begin{equation}
    \vec{u} = -\vec{F} - \boldsymbol{\chi}_1 + \frac{\partial\boldsymbol{\Phi}}{\partial\vec{q}_e}A(\vec{q}_e)(\vec{Z} + \boldsymbol{\Phi})
    - \left(\vec{q}_e^T \Lambda A(\vec{q}_e)\right)^T - \Gamma_z \vec{Z}
    \label{eq:fndo_bs}
\end{equation}
where $\Gamma_z \in \mathbb{R}^{2\times 2}$ is a positive definite gain matrix. Using the composite Lyapunov function $V = V_a + \frac{1}{2}\vec{Z}^T\vec{Z} + V_{e\chi}$, Theorem~2 of \cite{nadafiRobustBacksteppingAttitude2021} shows that $\dot{V}$ is negative definite for $\lambda_{\min}(\Gamma_z) > \frac{1}{2}$, guaranteeing global asymptotic stability of both $\boldsymbol{\omega}^r_e$ and $\vec{q}_e$.

\subsubsection*{Remark}

As discussed in Section~\ref{subsec:hypersurface_design}, the controller loses all authority over $q_{e3}$ when $q_{e1} = q_{e2} = 0$. This can be observed in the control law: substituting $q_{e1} = q_{e2} = 0$ into equation \eqref{eq:hypersurface} gives
\begin{equation}
    \boldsymbol{\Phi}\big|_{q_{e1}=q_{e2}=0}
    = -2\begin{bmatrix}
        a \cdot 0 \cdot q_{e3} + \lambda_1 q_{e0} \cdot 0 \\
        b \cdot 0 \cdot q_{e3} + \lambda_2 q_{e0} \cdot 0
    \end{bmatrix}
    = \begin{bmatrix} 0 \\ 0 \end{bmatrix}
\end{equation}
so $\boldsymbol{\Phi}$ vanishes for any $q_{e3}$. The corrective quaternion feedback term in the
control law also vanishes at this point: with $\vec{q}_e = [q_{e0},\,0,\,0,\,q_{e3}]^T$,
\begin{equation}
    \left(\vec{q}_e^T \Lambda A(\vec{q}_e)\right)^T = \vec{0}
\end{equation}
since the first two rows of $A(\vec{q}_e)$ couple only into $q_{e1}$ and $q_{e2}$.
Consequently, at $\vec{q}_e = [q_{e0},\,0,\,0,\,q_{e3}]^T$ with $\boldsymbol{\omega}^r_e = \vec{0}$:
$\boldsymbol{\Phi} = \vec{0}$, $\vec{Z} = \vec{0}$, and all quaternion feedback terms vanish,
reducing the control law equation \eqref{eq:fndo_bs} to
$\vec{u} = -\boldsymbol{\chi}_1 - \vec{F} \to \vec{0}$.
This is a closed-loop equilibrium for \emph{any} $q_{e3}$: the entire $q_{e3}$-axis is an
equilibrium manifold, and the controller is blind to a pure yaw error about
the unactuated $z$-axis once the actuated components have converged to zero.

This limitation is also visible directly in the Lyapunov derivative
(equation~22 of \cite{nadafiRobustBacksteppingAttitude2021}):
\begin{equation}
    \dot{V}_a
    = -a^2 q_{e3}^2\!\left(q_{e1}^2 + q_{e2}^2\right)
      - \lambda_1^2 q_{e0}^2\!\left(q_{e1}^2 + q_{e2}^2\right)
    \label{eq:Vadot}
\end{equation}
Every term is proportional to $\left(q_{e1}^2 + q_{e2}^2\right)$, so as the actuated axes
converge, $\dot{V}_a \to 0$ and all convergence---including that of $q_{e3}$---stalls.
The driving authority for $q_{e3}$ is quadratic in the actuated error, so it vanishes as the trajectory approaches the target.

This limitation is a significant practical concern as it means small manoeuvres which fail to sufficiently excite the actuated axes will leave the unactuated axis in an arbitrary orientation. This is particularly problematic for a satellite which may need to perform a slew manoeuvre to point at a target. If the unactuated axis is not sufficiently excited during the slew, the satellite may end up pointing in an arbitrary direction after the slew is complete. A way to counteract this behaviour is to construct a manoeuvre about the actuated axes which ultimately end at the desired attitude. The figures \ref{fig:large_angle_maneuver} and \ref{fig:small_angle_maneuver} illustrate this concept for large-angle and small-angle manoeuvres, respectively.

\subsection*{Modification for Hard Actuator Saturation}

The control law equation \eqref{eq:fndo_bs} requires unbounded torques and fails under hard actuator saturation i.e.: very low actuator saturation limits. The modified FNDO-BS (MFNDO-BS) controller replaces $\vec{u}$ with a saturated form through an auxiliary vector $\boldsymbol{\mu}$:
\begin{equation}
    \vec{u} = \alpha_1\,\mathrm{sat}_\delta(\boldsymbol{\mu}) - \alpha_2\,\mathrm{sat}_\delta(\vec{Z})
\end{equation}
where $\alpha_1, \alpha_2 > 0$ are scalar gains and $\boldsymbol{\mu}$ evolves via a stable auxiliary dynamics designed to compensate for the saturation nonlinearity. Theorem~3 in \cite{nadafiRobustBacksteppingAttitude2021} shows that the augmented Lyapunov function $V_1 = V_a + \frac{1}{2}\vec{Z}^T\vec{Z} + \frac{1}{2}\boldsymbol{\mu}^T\boldsymbol{\mu} + V_{e\chi}$ remains negative definite, giving global asymptotic stability even under saturation. This does however affect performance of the controller and when nominal operation occurs within actuator limits then it is unnecessary so this modification will not be considered for this thesis.

\subsection{Practical Considerations}
There are some practical considerations that must be taken into account when implementing the Nadafi and Kabganian controller. The first pertains to momentum dumping and the second pertains to continuous vs discrete-time implementation.


\subsubsection*{Angular Momentum Dumping}

Since there is the requirement that the total angular momentum to be zero, it is required to dump any residual angular momentum build up in the system from external disturbances. For demonstration purposes in this chapter, a perfect set of actuators is designed to be able to dump 3-axis angular momentum exactly from the system as follows:

\begin{equation}
    \vec{\tau_{dump}} = -k_{dump} \vec{H}^{BI}
\end{equation}
where $\vec{H}^{BI}$ is the total angular momentum of the system in the body frame and $k_{dump} = 1$ is the gain constant. 


In further chapters, a magnetorquer controller will be designed to bleed angular momentum from the system. This addition is not accounted for by the Nadafi and Kabganian controller and must be added:

\begin{equation}
    \vec{u} = -\vec{F} - \vec{\tau_{dump}^r} - \boldsymbol{\chi}_1 + \frac{\partial\boldsymbol{\Phi}}{\partial\vec{q}_e}A(\vec{q}_e)(\vec{Z} + \boldsymbol{\Phi})
    - \left(\vec{q}_e^T \Lambda A(\vec{q}_e)\right)^T - \Gamma_z \vec{Z} 
    \label{eq:fndo_bs_with_dump}
\end{equation}

Furthermore, the FNDO is designed to estimate the lumped disturbance $\vec{d}$ which includes the dumping torque. Since the dumping torque is known, it can be removed from the lumped disturbance and the FNDO can be used to estimate only the unknown disturbances. This is done by modifying the FNDO as follows:

\begin{equation}
    \dot{\boldsymbol{\chi}}_0 = \boldsymbol{\nu}_0 + \vec{u} + \vec{F} + \vec{\tau_{dump}^r}
    \label{eq:modified_fndo}
\end{equation}

\subsubsection{Continuous vs Discrete-Time Implementation}
Finally, it is important to note that the BS FNDO is a continuous controller and does not account for discrete-time implementation. In practice, the controller will be implemented in discrete time with a sample period $\Delta t$. The continuous-time control law is discretized using a zero-order hold, which can introduce additional dynamics and affect stability. For the simulations below a very fast sample time of $\Delta t = 0.01$~s is used. This mitigates the effects of discretization on the performance of the controller but is unrealistic for many controller applications. Designing the controller for discrete-time implementation will be an important area of future work.

\section {Attitude Tracking Manoeuvre Simulations}
\label{subsec:nadafi_tracking_sims}
To evaluate the performance of the Nadafi and Kabganian controller, a sequence of large-angle attitude tracking manoeuvres is simulated as a baseline scenario. All attitudes are commanded with respect to the inertial frame $F_I$, so the reference is inertially fixed between manoeuvres and no orbit-referenced (nadir) pointing is involved. The spacecraft is commanded to slew from its initial attitude to a target attitude, hold that attitude, and then slew back, before repeating the sequence for a second target obtained by mirroring the eigenaxis of the first. The reference trajectory is generated by interpolating between the waypoints listed in \autoref{tab:nadafi_track_waypoints} using SLERP (spherical linear interpolation) with smootherstep timing, so that the spacecraft comes to rest at every waypoint. The reference body rate $\boldsymbol{\omega}_d$ and angular acceleration $\dot{\boldsymbol{\omega}}_d$ required by the feedforward term $\vec{F}$ in equation \eqref{eq:fndo_bs} are obtained from this trajectory by central finite differences.

\subsection{Simulation Setup}
Each target attitude is a $70^\circ$ eigenaxis rotation about an axis lying in the body $xy$-plane, which is the plane spanned by the two healthy reaction wheels. Consequently the reference attitude has $q_{dz} = 0$ and the reference body rate has $\omega_{dz} = 0$ throughout, so the trajectory is admissible for the underactuated plant: the manoeuvre is large enough to excite the actuated axes, while never demanding torque about the unactuated $z$-axis. The manoeuvre is therefore representative of the favourable case identified in \autoref{subsec:hypersurface_design}.

The simulation parameters are summarised in \autoref{tab:nadafi_track_setup}. The spacecraft is modelled as a rigid body of mass $91\ \mathrm{kg}$ with the diagonal inertia matrix
\begin{equation}
    \vec{J}_0 = \begin{bmatrix}
        2.5 & 0   & 0 \\
        0   & 3.5 & 0 \\
        0   & 0   & 4.5
    \end{bmatrix} \mathrm{kg\,m^2}
    \label{eq:nadafi_inertia}
\end{equation}
taken from \cite{nadafiRobustBacksteppingAttitude2021} so that the results remain directly comparable with the original work. The inertia is diagonal, so there are no products of inertia to couple the axes beyond the gyroscopic coupling of equation \eqref{eq:sat_dynamics}, and it is held constant for the duration of the manoeuvre. Since the disturbance torque is prescribed analytically by equation \eqref{eq:nadafi_disturbance} and the momentum dumping actuator is idealised, the body geometry (face areas and centre-of-pressure offsets) does not enter the simulation and only the inertia and mass are relevant.

The spacecraft carries three orthogonally mounted reaction wheels, giving the distribution matrix $\vec{D} = \vec{I}$. Each wheel is modelled as a solid cylinder of mass $0.31\ \mathrm{kg}$, radius $66\ \mathrm{mm}$ and height $25\ \mathrm{mm}$, giving a spin-axis inertia of $J_w = 6.75\times10^{-4}\ \mathrm{kg\,m^2}$ and, at the maximum wheel speed of $10\,000\ \mathrm{rpm}$, a storage capacity of $0.71\ \mathrm{N\,m\,s}$ per wheel. The wheels start at rest and the spacecraft starts at rest, so the total system angular momentum is initially zero, $\vec{H}(0) = \vec{0}$, satisfying the necessary condition for stabilisability established in \autoref{sec:controllability}. The $z$-axis wheel is failed in the stuck (zero-torque) mode, so only the $x$- and $y$-axis wheels are commanded and the $z$-axis is unactuated. Wheel friction is neglected and the torque limit of $1\ \mathrm{N\,m}$ is never reached, so the saturated MFNDO-BS form of the control law is not required.

No multiplicative actuator fault is injected on the two remaining wheels: the actuator effectiveness matrix is $\vec{E} = \vec{I}$, hence $\boldsymbol{\rho}_w = \vec{0}$ and the lumped disturbance reduces to $\vec{d} = \{\vec{J}^r\}^{-1}\vec{T}_d^r$, which is the purely external disturbance
\begin{equation}
    \vec{T}_d = 7.5\times10^{-3}
    \begin{bmatrix}
        0.1 + 9\sin(0.5t) \\
        0.1 + 7.5\sin(0.8t) \\
        0
    \end{bmatrix} \mathrm{N\,m}
    \label{eq:nadafi_disturbance}
\end{equation}
used by Nadafi and Kabganian in \cite{nadafiRobustBacksteppingAttitude2021}. This is a deliberately aggressive disturbance, several orders of magnitude larger (and higher frequency) than the environmental torques derived in \autoref{chap:modelling}, and is retained here so that the disturbance rejection of the FNDO can be observed directly. Residual angular momentum is bled off with the idealised three-axis dumping law of equation \eqref{eq:fndo_bs_with_dump}, with the dumping torque removed from the observer input according to equation \eqref{eq:modified_fndo}.

\subsection{Results and Discussion}
From the simulation results shown in Figures~\ref{fig:fndo-bs_tracking_results}--\ref{fig:fndo-bs_tracking_results_chi_1}, it is clear that the FNDO backstepping controller is able to track the large-angle attitude manoeuvre in the presence of external disturbances. The controller is able to drive the actuated spacecraft quaternion errors $q_{e1}$ and $q_{e2}$ to zero, which in turn drives the unactuated quaternion error $q_{e3}$ to zero as well. The Euler angles $\psi$, $\theta$, and $\phi$ are also able to track their respective reference values with small errors. The disturbance rejection estimation errors $\chi_{1x}$ and $\chi_{1y}$ in figure \ref{fig:fndo-bs_tracking_results_chi_1} converge very closely to zero, indicating that the FNDO is able to accurately estimate the external disturbances.

Notice that the unactuated axis error $\psi_e$ gradually drifts from zero with each large manoeuvre. Also note the small amount of steady state chatter in the actuated axes $\theta_e, \phi_e$ and in the angular velocity error $\boldsymbol{\omega}_e$, a side effect of backstepping control. These two issues will be reduced by the magnetorquer controller in later chapters.

\section{Summary}
Satellite attitude control is a critical aspect of spacecraft operations, especially in the presence of actuator failures and external disturbances. The Nadafi and Kabganian FNDO-BS controller, which employs a finite-time nonlinear disturbance observer (FNDO) in conjunction with a backstepping control law, has been shown to effectively manage these challenges.
The controller's design allows it to handle large-angle attitude tracking manoeuvres, even when one of the reaction wheels is inoperative. The simulation results demonstrate that the controller can accurately track the desired attitude while compensating for external disturbances, as evidenced by the convergence of the disturbance rejection estimation errors to near zero.
